✂️ Flashcard Maker

Questions print on page 1, matching answers on page 2. Print double-sided, cut along the dashed lines — no glue, no laminator needed!

Bulk Import Format: question | answer — one per line

📋 How to print correctly:

1. Click Print Cards above.

2. In the print dialog, enable Two-sided / Duplex printing → Flip on Long Edge.

3. Print and cut along the dashed lines. Each card will have the question on the front and the matching answer on the back!

⚠️ Answers are mirrored on page 2 — this is intentional so they align correctly after flipping the page.
